# Read first
1. `git pull`, then read `docs/PROJECT_STATE.md` before doing anything. It is this app's memory.
2. Follow its **Session Rules**: recommend the cheapest capable model, size the job (S/M/L) with pause points, and if a `▶ RESUME HERE` block is at the top, start there.
3. **Every commit that changes the app also updates `docs/PROJECT_STATE.md`** (change log line + any section it made wrong). Never push without it.
